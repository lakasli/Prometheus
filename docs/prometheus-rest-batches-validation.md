# Prometheus 睡眠整理分批迁移

2026-10-31，Asia/Shanghai。依据原[架构9.7](architecture.md)、[日记契约](diary-system.md)，对照本机WSL中固定旧Rust `df6429cbceb8f16504efe9464c1abbbdb4a67e29` 的睡眠和日记实现。WSL独立合成实例只供参照，Windows验收另行记录。

## 已实现的范围

此前TypeScript睡眠整理仅处理前16个分区，而且把模型出域许可当作本地准备的前提；当天来源还会随普通采集变化。本批在受理睡眠的同一事务冻结获许可分区、策略版本、owner/可见域、时区、采集/遗忘水位、消息ID和已确认文字部分ID/确认时间。引用元数据不复制原聊天或模型正文。冻结之前已更正的事件按其现版本引用；之后更正发生时间也不能让旧日期检查失效。

收尾后每次处理最多16个来源、合计64条冻结消息，游标、排除原因和检查点持久化，继续后续页。仅允许本地采集时保存摘录或来源目录，不派发模型、不投影给Native；模型许可独立复核。运行中、控制/自动任务和被抑制输出排除，敏感正文不进入日记。渠道本人文字只使用冻结时已确认的部分；迟到回执和截止后的新消息不补入本批。

每个分区准备冻结当天的日记、最近一个已结束的周和自然月；缺少的已结束日父条目逐日补齐，周/月仅引用固定日版本，保留全量来源链和去重。沿用有界层次归并、来源/全局预算与共享单自动物理槽；片段成功后保存检查点，最终归并完成才发布模型正文。单日超过200条来源仍明确阻断，摘录超过正文预算不冒称覆盖完成。没有互动但缺少全天运行观测时不编造“当天无事”。

同一批重启从原快照继续；来源撤销/到期/续期开新水位、更正、遗忘或人工周期锁定使旧目标失效/阻断，不能覆盖人工正文。取消、原整理截止或独立唤醒中止未完成任务，保留部分结果与检查点，实际网络退出前不释放lease；不延长原wake_at/绝对上限。旧schema12活跃周期没有快照证据时保留期限并明确标记legacy_rest_snapshot_missing，不从现在倒推旧来源，不将其改报成功。

日程页新增本人管理范围内的最近10个批次，只显示来源/日期/阶段和排除状态，无原文。来源状态、各日周月和本地/模型处理分别展示。日记详情、Native资料投影与实际模型envelope均保留as_of；即使处理跨过午夜，也不能把冻结前的局部一天变成全天完成。

所有模型为合成loopback HTTP服务；“实际请求”指程序真实派发和接收该服务，不能视作真实远程模型、QQ/微信发送或客户端观察。跨午夜专项只在私有夹具保存旧日期快照，用当前系统时间检查投影/envelope；未改系统时钟，没有产品时间注入API，也不是实测跨夜。

开发中修复夹具run_targets列数/参数错误，以及误在draining阶段调用整理的问题；正式链本来只在consolidating推进。复核发现更正后的当前时间不能用于筛选旧快照，增加冻结事件时间和回归。另修复旧无快照周期被后续状态刷新误报完成的问题。页面来源序号类型检查曾失败，校正后重新构建和验证。失败日志保留于忽略目录。

本批只准备当天及最近已结束周/月，不补造全部停机历史或已有跨时区周期。冻结元数据在受理事务中生成，后续正文/模型按页处理；33来源通过不是十万规模性能证明。各来源分别成文；跨来源统一自我日记仍需明确交集授权，人物/好感自主睡眠写入、自动观察、真实模型/平台、媒体与Windows隔离工作器等仍未完成。原M2/M4/M5和整个迁移目标保持未完成。
