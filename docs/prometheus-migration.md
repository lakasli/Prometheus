# Prometheus 迁移范围

用户选择“全新项目重写，旧数据保留备份”。新实例不导入旧 DSH 数据库，不要求旧 API 路径兼容。原 [完整架构](architecture.md) 的功能目标继续保留。

当前[逐项完整性核对](prometheus-completeness-audit.md)确认仍未全部迁移；测试通过数不能替代完整性结论。
