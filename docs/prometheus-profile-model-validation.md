# Prometheus 显式日记人物候选迁移

2026-10-31，Asia/Shanghai。对照旧 `relationships_model.rs` 和[人物契约](relationships-system.md)，补齐明确日记来源的专用人物整理作业。固定发布、完整恢复及正式运行证据在实际执行后追加。

## 实现

管理者明确选择一个日记事件或周期事实条目、当前人物和最多10个同域目标后排队。来源须分别获日记采集和模型许可，事实正文不超过16000字节；周期感受栏、未选日记、其他人物和不可见域均不出域。主观日记事件单独标明subjective_note，事实栏为空，宿主拒绝把它升级为本人陈述/转述，只可生成标注推测的待审候选或空结果。私有人物不能借另一来源的共享许可转授私有称呼；同名、身份组和管理登录不扩大授权。

schema9作业只保存来源引用、人物/目标版本、许可版本、删除水位及幂等摘要；没有第二份日记正文或目标称呼。模型请求只在准入时读取当前合法内容，冻结当前配置，持续和提交事务内复核。最多8个字段和4条有向边，仅允许本人陈述、转述或推测。严格JSON拒绝重复/未知字段、模型自称核实、未选目标、非法日期、敏感依据、超限及未完整结束；候选事务整批提交或回退，只保存待审断言，模型不能批准、合并、改许可或外发。相同有来源候选去重，审核仍走独立冲突与版本流程。

队列全局最多32项；同秒按实际入队顺序取用。每实际来源域滚动24小时最多8次，全局24次，另受既有后台总预算约束，失败、中断和已取消请求不退额。额度不足保持排队并标明原因，不占用请求槽；一个来源预算不足不阻止其他有额度来源。与日记、日程等共用单个自动模型物理槽及全局并发上限2，交互优先；睡眠或时钟条件变化会中断在途请求，新的作业等待，不偷偷改来源或重试。

每次请求上限45秒，输出最多20000字节、2200输出token，请求完整JSON受48000字节及已声明模型窗口限制。尝试记录仅保留字节数、摘要、结束类型和错误类别；不保存原模型输出。逻辑取消、来源更正/撤销、人物或目标变化立即阻断旧结果，请求连接关闭后由所有者释放槽并清除配置引用，之前凭据不能删除。重启保留排队引用，物理尝试标中断且仍计额度，不自动重放；来源删除继续清除当前和历史候选正文。

管理页在人名详情展开“从日记整理待审核人物资料”，明确选择来源和目标并再次同意本次出域，显示排队、整理、待审核、失败、中断和取消。作业按人物分页，无历史人物的常驻进程；后台只扫有界活动队列，历史完成结果只在实际读取的页内复核。页面切换丢弃迟到响应，移除筛选目标时清空其选择并撤销确认，未保存选择受离开保护。完成不等于已批准或已生效。
