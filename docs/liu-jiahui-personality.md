## 展示与应用

- 导航、页标题与面包屑统一使用“性格与模型”，性格编辑以“她的性格”“姓名”等自然称呼呈现；品牌、登录、记忆、插件、日志等固定文案同步调整。
- API 标识、模型协议、供应商标识与原始审计信息保持真实，不篡改用户输入、历史记录或插件正文来消除特定字串。
- 新安装无既有性格、默认卡或自定义配置时使用刘嘉卉；升级不自动覆盖现有配置。正式实例通过认证、CSRF 与 If-Match 保存该资产为新性格版本，对后续入队请求生效。
- 稳定身份、模型配置、记忆及历史请求保持原归属。恢复性格仍通过历史版本保存为新版本；程序回滚与数据恢复分别处理。
