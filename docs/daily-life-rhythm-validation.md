## 当前实际范围

自主执行仅为四首目录诗的电子抄录，不是物理手写、外出或任意 Python 行为。通知选择覆盖固定作息与获授权、可移动的自主阅读／抄诗；人工锁定项目和其他系统任务不会因此获得模型修改授权。取消仅影响当前一次，推迟每次 1–30 分钟、最多两次，失败默认如期；取消起床仍保留绝对最长睡眠期限。
