# 嘉卉的小安排、固定作息与睡眠上下文

2026-10-27 用户确认：自己的小安排自动入日程并在可执行范围内留下结果；每天 Asia/Shanghai 07:00 起床、23:00 睡觉；提前一分钟通知模型选择如期、取消本次或推迟；睡眠时切断旧聊天上下文，日记保存记忆，运行日志保留原始记录。

## 性格

新资产为 [刘嘉卉性格 v2](examples/liu-jiahui-personality-v2.json)。编译器改用中性宿主操作约束，不再添加机械身份开场。嘉卉以人的第一人称视角交谈，自然接受明确补充的家人称呼与背景，不自行编造往事。直接询问真实技术情况时如实回答；安排、完成和送达继续以实际记录为依据。旧资产、已完成请求快照与历史验收不改写。正式实例通过认证、CSRF、If-Match 保存新性格版本；升级本身不覆盖保存内容。

## 聊天小安排

`GET/PUT /api/admin/v1/schedule/personal-policy` 管理独立版本化授权。初始关闭，开启时建立仅 `writing` 的普通自主授权，默认每天四次、每次十分钟，07:00–23:00，一年有效，可撤销。当前实际执行目录为《春晓》《静夜思》《鹿柴》《江雪》的电子抄录。不会据此宣称手写、外出或已具备任意写作、网络动作。

宿主按已有忙闲、授权、预算提供最多三个不早于七分钟后的时段，模型只选择目录 `poem_id` 和宿主 `slot_id`。回复可用 `{reply:[逐句回复对象],self_activity:{poem_id,slot_id}}`。最终保存回复 / Outbox 的同一事务内，以 Run 为幂等键登记活动；授权、时段或冲突变化会回滚本次登记，并阻止发送安排承诺。取消、纠正或无效来源的输出不登记活动。

执行共用原持久调度器，当前活动维护周期约三十秒，交互优先，无新增常驻 worker。电子抄录真实保存完整诗文、来源、SHA-256、实际起止和完成状态，同时生成只含目录原文的共享日记事件。共享视图不含原始聊天、来源 Run、owner、手工修改的目的或私人资源；普通阅读资料仍按原 owner 隔离。未注册的 writing 活动阻断，不按正文执行代码。

## 每日作息与一分钟通知

`RestPolicy` 新增 `anticipation_enabled`、`reset_context_on_sleep`，默认关闭，升级不自动开启。“日程”页可直接保存每日起床 / 睡觉和这两个选项；原独立作息管理保留。日历只读投影跨夜睡眠区间与起床项，不创建第二套睡眠计时器。

既有持久循环在到期前一分钟窗口建立唯一通知。作息和已有授权、可移动的自主阅读 / 抄诗活动可选择；人工锁定活动、系统整理、旧兼容触发及未交付的外发动作不因此获得修改权限。模型请求只带本次日程元数据、性格和宿主状态，不复用最近聊天。睡眠中的起床通知走同一受限模型额度，可以在普通聊天暂停时执行。

模型输出 `{decision:execute|cancel|postpone,delay_minutes:0或1..30}`，Native 宿主实际调用固定 [schedule_decision.py](../tools/actions/schedule_decision.py)，经宿主再次校验 policy revision、活动 revision、fence 和期限后提交。脚本只读标准输入、写标准输出，无路径、文件、网络、收件人或策略修改接口。一次机会最多推迟两次；取消只影响本次，不改每日固定时刻。通知请求最多45秒，模型失败、额度不足、进程中断或迟到输出保留原因，默认如期执行。独立决定额度每天最多24次 / 250000保守预留 token，与真实请求池和单自动任务准入共享，不伪称实际计费。

取消本次起床保留当前周期绝对最长睡眠上限；不会无限延长，管理员仍可唤醒。每次通知和选择追加到 `daily_life_decision_attempts`，保留原定时间、每次新期限、摘要及失败。`GET /schedule/decisions` 返回最近五十项及最多四次尝试，读取仍须认证，活动记录先按管理 owner 过滤。通知和脚本不会向 QQ / 微信发送消息。

## 睡眠边界与日记

受理睡眠时，先运行有界的获授权日记采集，再冻结整理来源截止，按会话保存独立 `sleep_context_boundaries`。它是提示上下文边界，不是删除水位：原始消息、实际投递记录和日志不删除，来源授权不扩大。

醒后的历史消息、会话摘要、时间连续性、话题与约定证据均受这个边界限制。睡前已冻结的在途输出在保存前重新校验边界，旧上下文不能借重试或缓存跨过睡眠。启用日记记忆模式时不再直接注入旧兼容记忆块，按原来源授权检索日记；旧显式记忆已通过原日记兼容机制保留。性格、稳定身份与当前有效人物资料不重置。

日记采集仍需明确来源授权，整理仍按既有来源、删除、模型出域及预算约束运行。未授权来源不会因开启上下文重置而自动采集；尚未采集的原始日志仍保留，后续有界批次可继续，不把“切断上下文”冒称全部历史已整理。原睡眠多批整理等未交付范围继续有效。

## 兼容与验证

发布能力为 `rest:2`、`daily_life:1`。保存新策略、建立小安排授权、生成决定或睡眠边界后，当前部署 / 回滚门禁拒绝不理解这些语义的旧版本；不删除记录绕过门禁。原可用版本、私有备份、模型 / 性格版本和实际 SHA 在本轮独立验收记录中记录。

代码和本契约本身不构成远端、浏览器或真实模型验收。合成隔离模型、实际外部模型、真实渠道投递分别记账，不宣称完整睡眠、通用脚本工具或完整 M2 / M4 / M5。
