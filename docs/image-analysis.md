# 独立PNG图片分析

这是单独的图片分析工作台。它只向现有DeepSeek账号的`deepseek-flash`发送一张经过校验的PNG和问题，返回分析文字，不自动写入聊天、角色卡、摘要或长期记忆，也不授予模型工具权限。实际部署与验收见 [图片记录](image-analysis-validation.md)，基础接口核实见 [视觉预检](vision-preflight.md)。

在控制台“图片分析”中选择PNG、核对本地预览、填写问题，再明确点击发送至DeepSeek。没有有效现有模型凭据或官方DeepSeek地址时页面显示不可用；此入口不另建付费账号、不静默切换其他云服务。用户可以取消或清除自己的任务；平台可能已经开始处理的请求无法承诺撤销计费，应用不会自动重发。

## 格式与出域

- 每次一张PNG，原文件最多1MiB，宽高各不超过2048、总像素不超过2097152；问题最多2000 UTF-8字节。JPEG、GIF、WebP、SVG与APNG均未开放。
- 服务端验证PNG签名、chunk长度 / CRC / 顺序、IEND、无尾随内容及无动画，再实际解码并规范为RGBA8、重新编码PNG；透明度保留，文本、ICC、EXIF等元数据不出域。只凭扩展名或浏览器预览不能绕过校验。
- 解码器内存预算32MiB、规范图片最多2MiB；单独CPU校验槽最多一个，不在SQLite锁内解码。只访问固定服务端接口，不允许提交外部图片URL给宿主抓取。
- 本地预览使用blob URL，换图、移除、提交成功、登录失效或离页时回收；不写浏览器持久存储。CSP仅为图片加入本地blob来源，脚本及网络来源限制继续由原策略执行。

## 调度、身份与数据

普通对话、记忆候选与图片分析共享配置允许的最多两个模型任务槽；普通聊天和候选排队优先。图片最多一个实际请求，全局最多两个排队 / 运行任务、每个owner一个活跃任务。每次请求最长30秒、只尝试一次；取消后保留占用lease直到真实HTTP future退出，重启将正在处理的任务记为interrupted，不重发。

每个任务冻结现有模型凭据引用和接口；活跃请求引用的凭据不能删除。生产入口只接受官方DeepSeek HTTPS地址；仅显式测试模式允许数值loopback HTTP。请求使用标准用户图像块、禁用思考，不请求工具、不展示内部推理。模型识图仍可能出错，页面结果是分析资料，不代表对图片内容作权威确认。

图片在完成、失败、取消或中断后清除活跃BLOB。成功结果与问题保留24小时，到期或明确清除后移除正文；失败 / 取消 / 中断也清问题和结果。保留无正文任务元数据和请求ID，用于幂等、版本与排障；最多1000条，达到上限拒绝新任务，不暗中删除仍需去重的旧ID。

这些是逻辑清除；SQLite WAL和离线备份按独立策略保留，不能声称磁盘字节同步被擦除。每个账户只能列出、读取或清除自己任务。结果只以转义文本展示，不执行模型生成的HTML。

## API

全部路径在认证、Origin / CSRF保护的`/api/admin/v1`内：

| 路径 | 行为 |
| --- | --- |
| `GET /image-analysis` | 当前可用性、固定provider/model、策略及本owner最近50条任务 |
| `POST /image-analysis/jobs` | `{client_request_id,image_base64,question}`；base64无data前缀；返回202任务 |
| `GET /image-analysis/jobs/{id}` | 本owner任务状态和有效结果，不返回图片或凭据 |
| `DELETE /image-analysis/jobs/{id}` | 当前整数If-Match；活跃任务取消，终态任务清除正文并保留metadata |

相同owner / 请求UUID / 规范像素与问题返回同一任务，避免重复派发和计费；同ID换内容返回409。网络结果未知时前端锁定并要求刷新核对，原样重试保留同ID；刷新后用户改问题，下一次明确提交才使用新ID，不自动发送。

首个实际任务同事务要求reader6及`standalone_image_analysis`发布能力，空表初始化不抬高门禁，删除正文不解除reader要求。产品`image_analysis.standalone=true`仅指此页面；`vision=false`仍表示普通聊天尚未接收图像。语音、渠道媒体与完整附件服务不在本切片范围。
