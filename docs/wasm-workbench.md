# 纯计算工坊

计算工坊是插件工厂的首个受限切片：管理员填写函数用途和至少两组不同输入的预期结果，明确提交给现有文本模型；服务端在独立Linux进程内编译WAT、验证策略并执行测试。测试全部通过才产生待审核制品。查看源码、测试结果、完整WASM与测试哈希、引擎和策略版本后，管理员另行批准，再手动输入两个i32整数执行。它还不注册聊天工具，也不构成完整M5插件工厂。

## 允许的程序

唯一ABI为`calc(i32,i32)->i32`，只允许纯整数计算。拒绝宿主导入、WASI、网络、文件、线性内存、表、全局变量、start函数、浮点、额外导出和组件。WAT与WASM各最多64KiB、函数最多16、locals最多64；每次调用使用新的实例，燃料100000、值栈64KiB、调用深度32。解析和执行均在worker内进行，Web浏览器不编译或执行生成的WASM。

模型只返回`{"wat":"..."}`；它不能申请权限、批准制品或提交shell命令。名称最多80 UTF-8字节、说明最多4000字节、测试2至8组，输入和预期输出均为i32。单次模型请求20秒，不自动重试。模型生成可能有错误，测试只覆盖给定样例，批准前应检查代码是否符合用途。

## 实际执行门禁

服务端启动时先检查固定worker运行方式；不可用时仅关闭工坊，普通聊天继续运行。Windows不提供该运行门禁。Linux使用精确UUID命名的用户级systemd服务，以当前发布的同一可执行文件运行隐藏的同步`wasm-worker --require-cgroup`入口，不创建Tokio线程池。

每次worker使用清空的环境和固定参数，设置MemoryMax=128MiB、MemorySwapMax=0、TasksMax=1、RuntimeMaxSec=5、TimeoutStopSec=1、KillMode=control-group及NoNewPrivileges。父进程核对systemd实际属性，子进程读取自身cgroup的实际文件并核对限额，之后才读取不可信程序。只有受限ABI和解释器参与执行，不依赖本机缺失的网络或挂载命名空间。它不为通用Harness内置工具提供隔离证明。

父进程记录自己创建的完整unit名称，取消、异常和重启只处理本数据库记录的精确unit；不批量扫描或停止相同前缀服务。无法确认退出时保留执行槽并关闭继续执行，避免在旧进程仍存活时放行新任务。资源压力验证是显式运维测试，应用启动不触发OOM或超时压力探针。

## 审批、身份与保留

生成、审批、执行、撤销均为独立动作。不可变制品保留WAT、WASM、测试、实际输出和哈希；批准绑定WASM哈希、测试哈希、引擎及策略版本。执行再次验证这些字段并冻结批准版本；撤销会停止排队与在途执行、拦截迟到结果，已完成的历史结果按原保留期限保存，不被伪称从未执行。

所有API要求管理员认证、Origin和CSRF校验，并按owner隔离；其他owner请求返回404。变更使用整数If-Match，过期版本返回409。生成与执行各使用请求UUID，相同内容返回原任务，换内容返回409；网络结果未知时必须刷新核对，不自动重新生成或执行。

全工坊最多两个排队或运行任务、每owner一个活跃任务，实际工坊任务最多一个，并与普通Native、记忆候选及图片分析共享模型/任务预算。普通聊天优先。生成说明在终态清除，执行输入和结果最长24小时，明确删除可提前清除；无正文任务元数据保留以维持幂等，最多1000条。制品最多100个，私有源码和测试在拒绝或撤销后仍保留，不自动覆盖或重新批准。逻辑清除不承诺清除SQLite WAL或离线备份。

首个实际任务或制品要求reader7与`pure_wasm_workbench`发布能力；只初始化空表或运行资源探针不抬高数据读取门禁。旧版本回滚仍须通过语义兼容检查。

## 管理接口

全部位于`/api/admin/v1/wasm-workbench`：

| 路径 | 行为 |
| --- | --- |
| `GET /` | 本owner任务、制品、策略及实际可用性 |
| `POST /generate` | 明确提交`client_request_id,name,spec,tests` |
| `GET /jobs/{id}`、`DELETE /jobs/{id}` | 查看、取消或清除本owner任务 |
| `GET /artifacts/{id}` | 查看私有源码、测试、哈希和结果 |
| `POST /artifacts/{id}/approve` | 提交两个完整哈希，批准当前版本 |
| `POST /artifacts/{id}/reject`、`/revoke` | 拒绝待审或撤销已批制品 |
| `POST /artifacts/{id}/execute` | 提交请求UUID、`a,b,wasm_sha256`，手动执行 |

验证状态以[工坊验收记录](wasm-workbench-validation.md)为准。通用WIT/Rust模板、隔离构建依赖、聊天工具激活和完整插件回滚仍待实现。
