# Prometheus 识图来源与临时输入迁移

2026-10-31，Asia/Shanghai，第十九批。对照旧Rust `conversation_images.rs` 与[图片契约](image-analysis.md)，修复第十八批已复现的描述角色、派生整理和临时BLOB缺口。完整迁移目标仍未达成，其他格式、规范化及渠道附件继续按[完整性核对](prometheus-completeness-audit.md)推进。

## 来源与上下文

视觉请求冻结模型、策略版本、原消息、会话/owner、上下文epoch和PNG字节摘要。当前图片和实际保留历史中依赖的视觉描述均以结构化user角色资料交给Native，系统层仅保存可信边界规则，不把视觉正文提升为系统指令。普通文字追问按实际发送的来源保存使用关系；来源失效、跨owner/会话、删除水位、epoch和中途撤销均重新检查。伪造正文标记不能建立使用关系，模型不能据此声称直接看到了原图或完整动态。

上下文预算移除完整旧回合，并同时重新计算其图像依据；没有实际发送的来源不记录为使用。历史中仍保留的派生回答可以追溯到原图来源，即使最初图片回合已被历史条数预算移出。Native请求快照保留真实角色和来源元数据，但省略视觉描述正文并明确标注，实际HTTP请求另用合成provider验证。普通Run/消息返回basis与图像状态、摘要和尺寸，不提供描述正文或临时原图。

直接图片回合不进入摘要或记忆候选；依赖识图的回答不再作为事实来源。普通文字追问的用户原文仍可单独用于候选，整回合的自动摘要继续排除。采集查询在分页前过滤，排队、派发、重试和批准时复核；日记采集也不将派生识图回答重新记为观测事实。兼容RecordItem入口检查权威日记状态，不能借保存的旧视图绕过待复核边界。管理页按整理方式禁用不允许的选择，切换方式会移除失效选择，服务端仍独立复核。

## 临时图与请求

普通上传在首次提交时与Run/来源记录同事务绑定，输入BLOB转入该Run的临时区，公共制品读取随即不可用。相同客户端标识、正文和图片引用返回原Run，清图后也不会重复发起模型请求；消息类型、正文或图片改变则冲突。绑定存储失败整体回滚，原上传仍可用于明确重试。图片问题拒绝控制命令。

视觉完成即清除临时输入，再调用Native；视觉失败、原回复失败、取消、遗忘、更正或已开始请求随服务退出时，输入与不应复用的描述清除。源请求完成时间由真实请求所有者退出时记录；逻辑取消不提前释放物理lease。已开始请求重启后中断且不重放；没有开始的合法队列可以首次执行。共享20份图像暂存配额按实际BLOB计算，已完成元数据不占用图像槽。

明确生成的下载成果有独立的原24小时制品期限；将其用于识图时，另建受同一上限约束的临时输入副本并按上述规则清除。已完成描述按原会话来源保留，不随临时下载TTL删除，后续更正/遗忘仍能失效。原始聊天、已确认投递、SQLite WAL和离线备份保留，不宣称物理擦除所有副本。描述校验拒绝非文字、截断、超过8000 UTF-8字节及秘密模式/当前已知凭据，不在失败后继续调用Native编造识图结果。

## schema16升级

新增来源、实际使用、旧会话水位和待复核事件元数据。schema15数据库在任何改动前自动快照，正式切换另备份完整实例及主密钥；旧15拒绝打开16，回退恢复匹配完整备份到独立目录。

旧版缺冻结模型和追问使用记录，不补造这些证据。旧已关联输入和描述退出活跃路径，原聊天及已保存资料保留；相关旧上下文和未批准整理任务失效。旧会话截止升级水位之前的回答不能重新充当事实来源；普通用户文字仍按当前许可单独处理。已有日记事件正文和版本保留，标记待复核；受影响的非人工锁定周期停止充当有效覆盖，兼容资料入口同样阻断。既有人工正文与锁定不被覆盖，完整原文覆盖和自动周期整理需先复核来源。明确更正对应事件后，新版本解除该版本的复核限制，随后按现有授权重建或整理；模型不能自行批准。
