## 行为与权限

- “模型与运行”保留直接应用入口，并新增可展开的草稿/操作管理。新凭据先单独加密保存；未保存的密码输入会阻止草稿保存/应用及直接表单应用，防止误用旧凭据。草稿和回执只含引用，不接受额外密钥字段、带凭据/查询的URL或任意执行方式。
- 草稿按账户隔离，最多32个、需显式删除；可保留空模型名/地址和未通过范围校验的整数，保存不会生效。字段校验、模型连接及QQ凭据检查分别显示，检查结果不自动应用。校验重新检查凭据类型和执行门禁。
- 草稿内容revision使用If-Match，base_revision与当前生效版本单独比较；跨页/重载后仍能继续。基准落后时列出全部字段差异，明确确认重新定位才可应用，不自动合并覆盖其他编辑。应用再做严格校验与全局CAS；已应用草稿只读，另存才可编辑。重复应用返回原不可变回执，不新增配置版本；历史应用和当前生效明确区分。
- 异步检查返回202，先请求实际模型、再为已启用QQ尝试取访问凭据；QQ检查不更新运行token缓存、不激活账户、不上传/发消息。上游响应正文、token及密钥不入回执。直接表单检查沿用同步响应，并持久保存同类回执。
- 两种检查共享单个检查器，计入全局物理请求槽。编辑/删除草稿、取消或退出会中断请求；凭据引用和请求槽在连接退出后释放，不能因逻辑取消提前重用。本批也将成功JSON响应延后至连接关闭才交还槽。停止时先禁止Runtime继续调度，避免释放检查槽后启动原排队消息。重启将孤立检查标记interrupted且清除临时配置快照，不自动重试检查；普通未执行Native队列仍按原约定恢复。
- 所有草稿/操作接口在认证、精确Origin、CSRF边界内；其他管理员无法读取、应用或取消他人的对象。执行门禁继续拒绝语音、Harness与插件，草稿不能开启它们。
