# Prometheus 日记周期迁移验收

2026-10-31，Asia/Shanghai。第八批对照旧Rust diary、diary_aggregation、diary_model和[原日记契约](diary-system.md)。此前TS的day/week/month只是选中来源后的标签，没有真实封存、固定父版本或周期覆盖；普通Native也只读取显式记忆。本批恢复这些主链路。正式发布结果在实际验收后追加。

## 数据与权限

事件记录实际发生时间、观察时间、陈述类型、owner、原资料/消息ID及版本；明确事件创建需要幂等键。更正清除旧版本正文，遗忘保留ID水位，重复导入不能复活。私有按管理主体和来源隔离，共享事件须逐条明确发布；会话来源不改成共享。来源采集、模型出域和作息控制保持独立。自身明确记录默认私有，模型许可默认关闭。

既有TS采集grant沿用原enabled_after建立日期分区，不要求重复授权；只采集授权水位后的完成互动。每轮最多64个完成Run、16个来源，排除本地控制、自动任务、疑似凭据。晚完成的早输入不会被最大消息游标跳过；渠道回复等投递终态后只记录确认sent的部分，unknown不冒充送达。原始聊天保留；日记事件更正/遗忘或采集撤权后的旧原文禁止再次提取。

旧人工记忆和无派生来源的人工日记保留在原表并登记有来源事件；更正同步当前revision，遗忘可从原资料或事件入口处理。模型候选及已有来源派生日记不回灌成新原始经历。没有导入旧Rust数据库、旧凭据、历史未知发送或Breeze未提交改动。

## 日周月与模型覆盖

按IANA民用日期划分，周一至周日、月为自然月。当地00:05之后从持久检查点补记，每来源每轮最多4个有来源日期；无事件的结束日期可有界补齐最多7/31份明确未观测空父。没有完整运行观测不称当天无经历；民用历法跳过日期单独说明。进行中日期显示open、截止时刻及period_closed=false，不称全天封存。人工未来经历和未来模型整理请求拒绝。

周/月记录固定的日父版本及所有原始来源，月记不叠加跨月周记。父版本后续从完整摘录丰富为模型正文，不使已选择的完整旧版本失效；未覆盖完整的父内容必须等待。来源指纹不变不新增周期版本；缺父任务不占物理lease，选择器继续检查就绪任务。单日超过200条明确阻断，仍登记完整来源链；周/月不把来源截到前200条。

初版是evidence_excerpt_v1摘录或parent_catalogue_v2目录，不能冒充模型全周期总结。摘录12KB附近截断时标覆盖不完整。每次完整provider JSON不超过48,000字节，最多2400输出token/45秒；父集合与原始事件分批，成功保存level/ordinal、连续覆盖范围和输入摘要，再归并全部前层片段。只有最终单批覆盖某层全部单元后，才发布model:<模型名>和完整覆盖。每片最多3次连续失败、至少60秒冷却，成功清零本批失败数。滚动24小时每来源owner最多8次、日记全局24次，另受已有全局预算与共享自动单槽/总并发2限制；交互优先，失败/取消/未知消耗不退款。

只接受完整JSON或完整json/无语言围栏；语言标签不区分大小写，其他语言、前后杂文、重复及未知字段拒绝。事实/感受硬上限900/160 Unicode码点、完整文字6000字节。finish_reason=length即使JSON闭合也拒绝，过滤/工具/其他非正常结束亦拒绝；普通文本客户端仍返回content，日记单独使用受限枚举元数据。诊断保存hash/字节/固定结束枚举/解析状态，不保存回复正文或任意provider元数据。

原网络连接关闭后才释放lease/凭据引用。取消、源/授权版本改变、周期结束及退出阻止旧结果提交；重启保留成功片段，对未完成尝试标interrupted，经过冷却、权限和额度复核再准备新片段，不重放旧HTTP请求。睡眠整理采用相同来源账本，带cycle_id，只等待本次周期任务，原唤醒期限保留。

## 纠正、遗忘与普通对话

遗忘任一原始来源使完整日/周/月链、各版本正文及所有层级片段失效；310条来源的末条也会命中，旧手工派生资料继续级联。撤销采集清除已采集正文并保留水位；恢复只采新授权后的互动。只关闭模型许可保留已授权采集事件，清理旧派生和上下文，不退化为重新提取旧原文。人工正文锁定，不被周期调度覆盖；需当前版本加明确replace_manual确认才能从当前来源重建。

认证管理检索使用独立事件/周期FTS、日期/来源/周期筛选与分页。只有分区和原来源模型出域均有效时，才生成Native可见投影。Native先按问题检索日记，无命中最多四份近期可见日记，标recent_visible_day；事实与主观感受分开，UTF-8截断且完整JSON不超过8000字节。实际来源ID/revision/原因记入context_selections，隔离运行不读取日记。撤权/失效后清理投影和旧prompt快照，避免借普通对话绕过模型许可。

管理页提供事件更正/遗忘、周期摘录与覆盖、固定父版本、执行诊断、明确模型请求、失败重试、人工锁定/重建与分页导出。未保存表单参与离开/关闭检查。已有数据的时区变更拒绝，需后续明确周期迁移；空分区可选择时区。
